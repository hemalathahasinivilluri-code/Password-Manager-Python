# Password Manager using Python

A command-line based Password Manager built using Python to securely store and manage passwords.

## Features
- Master password authentication
- Add new passwords
- View saved passwords
- Search passwords
- Delete passwords
- Base64 encoding for secure storage

## Technologies Used
- Python
- File Handling
- Base64 Encoding
- Exception Handling

## How to Run
```bash
python password_manager.py
